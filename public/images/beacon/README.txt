The Beacon's weekly page pictures live here.

NAME THEM LIKE THIS
  2026-09-13-page-1.jpg      the Sunday, then -page-, then the number
  2026-09-13-page-2.jpg      page 1 is the front

  Year first so they sort themselves, and so 09-13 can never be misread as the
  ninth of December. Lower case, hyphens only: no spaces, commas, apostrophes
  or capitals. A comma costs every visitor a redirect before the browser is
  allowed to have the picture.

SAVE THEM AS JPEG, NOT PNG
  A PNG of a full page can be ten megabytes and takes a long while to open on
  a phone. The same page as a JPEG is under one and looks identical.

DO NOT WORRY ABOUT THE WHITE BORDER OR THE SIZE
  Every build crops the blank canvas off and caps the width at 2000px, whoever
  uploaded the file and however. Upload exactly what your design tool gives
  you. Nobody has to ask for this and nobody has to run anything.
